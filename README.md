# Reimbursr

Teaching artifact for the O'Reilly live course **"Human-in-the-Loop AI Development."**

---

## Repository Structure & Branches

This repository uses a branch-per-checkpoint layout designed to follow the course narrative step-by-step:

* **Main Branch:** Includes all prompts, agents, and final results of the course.
* **Segment Branches:** Every segment has its own dedicated branch following the nomenclature `<segment_number_title>` (e.g., `1_intro_to_agents` or `s1-blind-trust`). Later checkpoints build directly on earlier ones, allowing you to check out any branch to see the exact state of the app at that point in the course.
* **Solved Versions:** In some cases, a branch has two different versions:
* The initial state before changes are applied.
* A corresponding branch with the `_SOLVED` prefix containing the completed changes.



> **Note on Bugs:** Some code in this repository contains intentionally planted bugs used for live demonstrations. These are clearly marked with `// COURSE-BUG(sN): <description> — DO NOT FIX` comments and should never be repaired outside of the course narrative.
