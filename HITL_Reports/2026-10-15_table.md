# HITL Report: 2026-10-15

**Task:** Export approved expenses for accounting as a spreadsheet-openable file download.

## Verdicts

| Agent | Verdict |
|---|---|
| write-code | The CSV export already existed (commit 6c524fa). It was hardened against formula injection and given a UTF-8 BOM. Not run or downloaded. |
| check-quality | The formula prefix changes data, not just formulas: amounts like `+100` become text and SUM skips them silently. Separately, the page does not run when opened directly from disk. |
| check-security | The prefix stops formulas in form-submitted data, but there is no access control on the queue or the export, and the reviewer page renders employee input as raw HTML, so an employee can run script, approve their own claims and control the exported file. |

| Aspect | Behavior |
